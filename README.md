# Nepal 2026

App web (PWA) del viaje a Nepal de Rose y Alejandro: plan de Katmandú por días, logística, trek, presupuesto y diario.

- Se publica con GitHub Pages desde la rama `main`.
- Los datos se sincronizan con una hoja de Google Sheets a través de un Apps Script. La palabra de acceso no está en el repositorio: se escribe una vez en la app y se guarda en cada dispositivo.
- Funciona sin conexión; los cambios se suben solos al volver la red.
- El tiempo viene en directo de Open-Meteo.
